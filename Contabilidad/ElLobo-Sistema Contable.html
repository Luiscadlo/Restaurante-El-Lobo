Exportación completa de datos para análisis externo (Excel/Python).
💾 Respaldo completo (copia de seguridad)
Descarga un archivo .json con TODAS las tablas del sistema, completas (pedidos, egresos, cierres, caja, fiados, inventario, auditoría…). Es la copia que sirve para recuperar el sistema si algo falla (se restaura aquí mismo, con la tarjeta «Restaurar desde un respaldo» de abajo). Hazlo cada domingo y guarda el archivo fuera del repositorio (que es público). Solo se registra como hecho si bajaron todas las filas.
♻️ Restaurar desde un respaldo
📌 Importante — usa solo el archivo original del respaldo.
  • Solo sirve el archivo .json que crea «Hacer respaldo completo» (se llama ElLobo_respaldo_completo_AAAA-MM-DD.json). Ese es el único formato que entiende el sistema.
  • No lo abras ni lo edites ni lo guardes con otro programa (Excel, Word, Bloc de notas…) y no le cambies el formato: un archivo modificado se rechaza y, si lo cambiaras a mano, perderías esos datos.
  • El Excel de «Exportar datos» no sirve para restaurar: es solo para análisis.
  • Restaurar reemplaza todo lo que hay ahora por lo que trae el archivo. Antes de tocar nada, el sistema te muestra qué cambia y descarga una copia de lo actual.
🧹 Empezar de cero
Borra los datos de trabajo (ventas, fiados, cierres, gastos, caja…) para empezar con el sistema vacío, por ejemplo al terminar las pruebas y salir a trabajar de verdad. Las mesas se conservan. Es irreversible (salvo restaurando un respaldo): antes de borrar, el sistema descarga una copia de todo lo actual y te pide la palabra de confirmación y tu contraseña.
📊 Exportar datos a Excel
Para análisis (no es una copia de seguridad). Genera un Excel (.xlsx) con una hoja por cada tabla del sistema (pedidos, egresos, cierres, caja, inventario, etc.) — pensado para análisis externo en Excel o Python (es el archivo que lee el modelo financiero). No se puede restaurar desde aquí: para la copia de seguridad usa la tarjeta «Respaldo completo» de arriba.
Período de los datos históricos a descargar
O elige los meses: –
Se exportan meses completos (del día 1 al último día), así el modelo no trata un mes partido como si fuera un mes entero. Sin período = todo el historial. Inventario, pedidos pendientes (fiados), clientes y abonos de fiado y movimientos de caja siempre van completos: son el estado actual (saldos), no un histórico por fechas.
